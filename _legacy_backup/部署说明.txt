AI工具合集 - 服务器部署说明
========================================

【部署前提】
  1. 服务器需安装 Node.js（本机验证版本建议 v18 及以上，v20/v22 最佳）
  2. 服务器需能访问以下数据库（本包为"查询端"模式，连的是原库地址）：
       达梦 DM   192.168.0.32:5236   (库: DETECTION, 账号 CHXJ)
       SQLServer 192.168.0.30:1433   (库: Elims, 账号 Elims)
     （如果数据库地址变更，只需改 unified-pool\server.js 顶部配置）

【解压部署】
  1. 把 AI工具合集_部署包_20260824.zip 上传到服务器
  2. 解压到任意目录（例如 D:\AI工具合集）
  3. 解压后目录结构应如下（7 个子目录平级）：
        D:\AI工具合集\
          ├─ AI工具合集\          <- 导航首页 + 一键启动/停止脚本
          ├─ unified-pool\        <- 中间池(4000)，数据库账号密码在这里
          ├─ 20260605160640\      <- LIMS统计查询(3001)
          ├─ sqlserver-query-tool\<- 旧LIMS查询(3003)
          ├─ 数据看板\            <- 数据看板(3005)
          ├─ 人员能力表梳理\      <- 人员能力(3007)
          └─ cma-checker\         <- 一单一库核对(3002，独立工具)

【启动】
  双击 AI工具合集\一键启动.bat
  会自动：启动导航(8080) + 中间池(4000) + 5个工具(3001/3003/3005/3007/3002)
  全部就绪后自动打开导航首页。

【停止】
  双击 AI工具合集\停止服务.bat 一键关闭。

【端口】
  8080 导航 | 4000 中间池 | 3001/3003/3005/3007 数据库工具 | 3002 独立工具
  若端口被占用，修改各目录 server.js 顶部的 PORT 即可。
 注意：数据看板(3005) 已升级为 FastAPI + Vue3，由 数据看板\backend 启动
       （conda 环境 dashboard + uvicorn，页面为 http://localhost:3005/），不再是 server.js。

【常见问题】
  - 数据库连不上：检查 unified-pool\server.js 顶部连接配置，及服务器到 192.168.0.32/30 的网络。
  - 原生模块报错（dmdb/mssql）：本包 node_modules 为 Windows 编译版，若服务器 Node 版本差异大，
    需在对应目录执行 npm install 重新编译。
  - 一单一库核对(3002)需要服务器能访问外网 cma.caqit.org.cn。
